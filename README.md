# AIを味方に探す｜海外在宅ワーク完全スタートガイド

Instagramリールのフォロワーに配布する特典ページです。LinkedInで海外在宅ワークを探す方法から、
AIを使った求人確認・応募準備・実務効率化までを、初心者向けに1ページで解説しています。

コードやデザインの知識がなくても、`js/content.js` というファイル1つを書き換えるだけで
文章やリンクを更新できます。このREADMEは、パソコンの操作にあまり詳しくない方でも
迷わないように、専門用語をできるだけ避けて説明しています。

このリポジトリは `mion-ai-mama/instagram-tokuten-template` を「Use this template」で
複製して作った、このページ専用のリポジトリです。

## 1. 変更するファイル

| ファイル | 説明 | 編集頻度 |
|---|---|---|
| `js/content.js` | ページの文章・プロンプト・リンク・表示ON/OFFをまとめたファイル | **メインで編集する** |
| `assets/images/` | 画像ファイルの置き場所（LinkedIn画面のスクショ・OGP画像など） | 公開前に必ず |
| `index.html` の `<head>` 内 | SEO用の説明文（検索結果に出る文章） | できれば毎回確認 |
| `css/style.css` | 色やデザイン | 基本編集不要 |
| `js/script.js` | ページの動き（コピー機能・チェックリスト保存など） | 編集不要 |

## 2. content.js の編集方法（基本）

`js/content.js` をテキストエディタ（メモ帳や、GitHub上の鉛筆アイコンでも可）で開くと、
日本語の文章がたくさん並んでいます。

```js
hero: {
  label: "AI初心者さん向け",
  titleLine1: "AIを味方に探す",
  titleLine2: "海外在宅ワーク完全スタートガイド",
  ...
```

`"　　"`（ダブルクォーテーションで囲まれた部分）の中の日本語だけを書き換えてください。

**触ってはいけない部分**：`:`（コロン）、`,`（カンマ）、`{ }`（波かっこ）、`[ ]`（角かっこ）、
`<br>`（改行を表すタグ。残したまま、前後の文字だけ変えればOK）。

書き換えたら保存して、`index.html` をブラウザで開けば、変更が反映されているか確認できます。

## 4. STEPの変更方法（プロンプト・画像・検索キーワード）

`content.js` の `steps` 配列を書き換えます。`{ }` のかたまり1つがSTEP1つ分です。

```js
steps: [
  {
    number: "STEP 1",
    title: "（STEPの見出し）",
    paragraphs: ["（本文の段落1）", "（本文の段落2）"],
    list: ["（箇条書き1）", "（箇条書き2）"],
    afterParagraphs: [],
    image: { placeholder: "ここに◯◯の画像を追加", src: null, alt: "（画像の説明）" },
    note: null, // 補足ボックスが必要なら { label: "補足", text: "（補足文）" }
    keywordList: null, // 検索キーワードのコピー一覧が必要なら { heading: "…", items: ["…", "…"] }
    prompts: [], // プロンプトボックスが必要なら [{ id: "prompt-01", title: "（見出し）", text: `（本文）` }]
    cautionBox: null, // 注意ボックスが必要なら { variant: "soft" または "strong", text: "（本文）" }
  },
  ...
]
```

- **STEPの数は自由に増減できます。** 増やすときは `{ }` を丸ごとコピーして追加、減らすときは
  丸ごと削除するだけです。
- **画像**：`image.src` が `null` の間は「ここに◯◯の画像を追加」というプレースホルダーが
  表示されます。画像を用意したら `src` にパスを入れてください（[7章](#7-画像を追加する方法)参照）。
- **プロンプト**：`prompts` 配列に追加した数だけ、コピーボタン付きのプロンプトボックスが
  そのSTEPに表示されます（1つのSTEPに複数個も可能。STEP8では2個使用しています）。
- **注意ボックス**：`variant: "soft"` は目立たない通常表示、`"strong"` はオレンジ系の
  目立つ表示になります（STEP8のAI利用ルール確認で使用）。

## 5. チェックリストの変更方法

STEP9の応募前チェックリストは `content.js` の `checklist` を書き換えます。

```js
checklist: {
  number: "STEP 9",
  heading: "応募前チェックリスト",
  description: "（説明文）",
  items: ["（チェック項目1）", "（チェック項目2）", ...],
},
```

`items` の数を増減させれば、チェック項目の数も自動で変わります。読者がタップした
チェックの状態は、読者のブラウザに保存され（`localStorage`）、ページを再読み込みしても
消えません。この保存内容はサーバーには送られず、他の人には見えません。

## 6. CTAリンクの変更方法

ページ最後の案内ボタンのリンク先は、`content.js` の `cta.buttonUrl` の**1か所だけ**を
変更すれば反映されます。

```js
cta: {
  ...
  buttonUrl: "https://example.com/", // ← ここをLINE登録URLなどに変更
  bannerImage: null, // バナー画像を使う場合はパスを指定。使わない場合は null（通常のボタン表示）
  bannerAlt: "（バナー画像の内容を説明する文章）",
},
```

## 7. 画像を追加する方法

1. `assets/images/` フォルダの中に、画像ファイル（jpg・png・webpなど）を入れる
2. 使いたい場所に応じて、`content.js` 内のパスを書き換える
   - STEP1・STEP2の画像 → 該当するSTEPの `image.src`
   - OGP画像（SNSシェア用）→ `meta.ogpImage`（**https://から始まる絶対URL**にしてください）
3. ファイル名は半角英数字がおすすめです（日本語ファイル名はトラブルの原因になりやすいです）

## 8. セクションのON/OFF

今回使わないセクションがある場合、`content.js` の一番上のほうにある `sections` を
書き換えるだけで非表示にできます。

```js
sections: {
  guideFlow: true,     // 「このガイドの流れ」目次
  canDo: true,          // このガイドでできること
  disclaimer: true,     // 冒頭の注意書き
  steps: true,           // STEP1〜8
  checklist: true,       // STEP9 応募前チェックリスト
  finalSummary: true,   // 最後のまとめ
  cta: true,              // 最後の案内（CTA）
},
```

`true` → 表示 / `false` → 非表示。非表示にした文章は消えるわけではないので、
あとで `true` に戻せば元通り表示されます。ファーストビューとフッターは常に表示されます。

## 9. GitHub Pagesで公開する方法

1. このリポジトリのGitHubページ（`https://github.com/mion-ai-mama/linkedin-remote-work-guide`）を開く
2. 上部メニューの **「Settings」** をクリック
3. 左側のメニューから **「Pages」** をクリック
4. 「Build and deployment」の「Source」で **「Deploy from a branch」** を選ぶ
5. 「Branch」で **「main」** と **「/ (root)」** を選び、「Save」をクリック
6. 数分待つと、ページ上部に公開URLが表示されます
   （`https://mion-ai-mama.github.io/linkedin-remote-work-guide/`）

> 💡 このリポジトリに変更をpushするたびに、GitHub Pagesは自動で更新されます。

## 10. 公開後のURLの確認方法

1. GitHubのリポジトリ画面 → 「Settings」→「Pages」を開く
2. ページ上部に「Your site is live at ～」という緑色の表示があれば、そこにURLが表示されています
3. そのURLをコピーして、ブラウザで開けば公開状況を確認できます
4. Instagramのプロフィール欄やリンク集ツールに、そのURLを貼り付けてください

## 11. よくあるエラーと対処方法

| 症状 | 原因の可能性 | 対処方法 |
|---|---|---|
| ページが真っ白になる | `content.js` の書き方に誤り（カンマの消し忘れなど） | 直前に保存した内容に戻し、1か所ずつ変更して確認する |
| 文章が反映されない | ブラウザのキャッシュが残っている | スマホ・PCともに再読み込み（強制リロード）する |
| コピーボタンが反応しない | 古いブラウザ、またはページを`file://`で直接開いている | GitHub Pages公開後のURL（`https://`）で確認する |
| チェックリストの状態が消える | ブラウザのプライベートモードで閲覧している、またはサイトデータを削除した | 通常モードで閲覧すれば、次回以降は保持されます |
| セクションが消えない/表示されない | `sections` の `true` / `false` を書き間違えている | スペルミス（`ture`など）やカンマ抜けがないか確認する |
| 公開URLが404になる | GitHub Pagesの設定がまだ反映されていない | 数分待ってから再度アクセスする |
| 画像が表示されない | ファイル名の大文字・小文字違い、拡張子違い | `assets/images/` 内の実際のファイル名と `content.js` の記載を見比べる |

## 12. スマートフォン表示の確認方法

- 実際にスマートフォンのブラウザで公開URLを開いて確認するのが一番確実です
- パソコンで確認したい場合は、Google Chromeの「検証」機能（右クリック→検証）から
  スマホ画面のシミュレーション表示に切り替えられます
- 特に確認したいポイント
  - 文字が小さすぎないか
  - ボタン・コピーボタンが押しやすい大きさになっているか
  - 横スクロールが発生していないか
  - コピーボタンを押すと「コピーしました」と表示されるか
  - チェックリストをタップしてチェックが入るか

## 技術的なメモ（参考情報）

- ビルド（変換作業）は一切不要です。HTML・CSS・JavaScriptだけで動く「静的サイト」です
- React・Next.js・Vue・データベース・サーバーは使用していません
- 外部の有料サービスへの依存はありません
- フォントは各OSに標準で入っているフォント（システムフォント）を使用しています
- STEPセクションは `js/content.js` の `steps` 配列から `js/script.js` が自動的に組み立てます。
  `index.html` 内のSTEP部分は、JavaScriptが読み込めなかった場合の初期表示用（フォールバック）です
- チェックリストの状態は `localStorage`（読者のブラウザ内）に保存されます。サーバーへの送信は行いません
